# SistemaPeliculas

Este programa en Python permite gestionar un sistema de votación de películas organizado por una academia ficticia, 
en el cual los estudiantes pueden votar por sus títulos favoritos en distintas categorías.

## Funcionalidades

El sistema permite:

1. Registrar películas en categorías como:
   - Mejor Guion
   - Mejor Dirección
   - Mejor Banda Sonora
   - Mejor Animación
2. Registrar votos por películas previamente ingresadas.
3. Mostrar los resultados actuales (cantidad de votos por película).
4. Determinar la película ganadora en cada categoría.
5. Salir del programa.

Es indispensable que el usuario ingrese de forma correcta los datos solicitados
si no el programa retornara un mensaje explicando el porque no se permite los datos ingresados y sugerira una mejor opción
